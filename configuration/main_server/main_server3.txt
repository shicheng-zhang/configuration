###############################################################################

===============================================================================
STAGE 1: PHYSICAL & iLO 3 (REMOTE MANAGEMENT)
===============================================================================
1. Connect Ethernet to the dedicated iLO port (labeled on rear).
2. Boot -> [F8] at iLO prompt.
3. Network -> DNS/IP -> Static IP: 192.168.1.49 / Subnet: 255.255.255.0.
4. From Laptop: Browser -> https://192.168.1.49 (Login with tag credentials).
5. Thermal Config: Power Management -> Fans -> "Optimal Cooling".
6. Power Config: Power Management -> Server Settings -> Power-On Delay -> "Random".

===============================================================================
STAGE 2: BIOS & STORAGE CONTROLLER (THE "ZFS TRICK")
===============================================================================
2.1 BIOS HARDENING [F9]
- System Options -> Processor Options:
    * Intel VT-d: Enabled
    * Hyperthreading: Enabled
- Power Management: 
    * HP Power Profile: Maximum Performance
- Advanced Options:
    * Fan Service: Increased Cooling (If using high-temp SSDs)

2.2 STORAGE ARRAY [F8]
- Enter Smart Array P410i Utility.
- Create 3 separate "Logical Drives".
- Each must be RAID 0 and contain exactly ONE physical disk.
- Result: sda (980GB), sdb (980GB), sdc (980GB).

===============================================================================
STAGE 3: PROXMOX VE 8.x INSTALLATION
===============================================================================
1. Flash ISO using Rufus (DD Mode) or Ventoy.
2. Boot [F11] -> Select USB.
3. If installer freezes: Highlight "Install Proxmox VE (Graphical)", press 'e', 
   add "nomodeset" to the end of the 'linux' line, press Ctrl+X.
4. Target Disk -> Options:
    * Filesystem: zfs (RAIDZ-1)
    * Select all 3 drives (sda, sdb, sdc)
    * ashift: 12
5. Management Network:
    * Hostname: ironclad.lan
    * IP: 192.168.1.50
    * Gateway: 192.168.1.1 (Router IP)

===============================================================================
STAGE 4: POST-INSTALL OPTIMIZATIONS (SHELL COMMANDS)
===============================================================================
--- 4.1 UNLOCK DISK SPEEDS (Force Cache) ---
apt update && apt install -y ssacli
ssacli ctrl slot=0 modify ld=1 forcedwritecache=on
ssacli ctrl slot=0 modify ld=2 forcedwritecache=on
ssacli ctrl slot=0 modify ld=3 forcedwritecache=on

--- 4.2 REPOSITORY FIX (No-Subscription) ---
rm /etc/apt/sources.list.d/pve-enterprise.list
echo "deb http://download.proxmox.com/debian/pve bookworm pve-no-subscription" > /etc/apt/sources.list.d/pve-no-subscription.list
apt update && apt dist-upgrade -y

--- 4.3 RAM MANAGEMENT (72GB Total) ---
# Cap ZFS ARC to 8GB to leave room for VMs
echo "options zfs zfs_arc_max=8589934592" > /etc/modprobe.d/zfs.conf
update-initramfs -u

--- 4.4 PERSISTENCE SCRIPT (Auto-apply cache on reboot) ---
cat <<EOF > /etc/systemd/system/p410i-cache.service
[Unit]
Description=Force P410i Write Cache
After=local-fs.target

[Service]
Type=oneshot
ExecStart=/usr/sbin/ssacli ctrl slot=0 modify ld=1 forcedwritecache=on
ExecStart=/usr/sbin/ssacli ctrl slot=0 modify ld=2 forcedwritecache=on
ExecStart=/usr/sbin/ssacli ctrl slot=0 modify ld=3 forcedwritecache=on
RemainAfterExit=yes

[Install]
WantedBy=multi-user.target
EOF
systemctl enable p410i-cache.service && reboot

===============================================================================
STAGE 5: STORAGE HUB (NAS) - PRIVILEGED LXC
===============================================================================
1. Create CT: ID 100, Debian 12, Disk 20GB, RAM 4GB, IP 192.168.1.51.
2. Create Storage Pool on Host: zfs create rpool/data && chmod 777 /rpool/data
3. Bind Mount to CT: 
   Edit /etc/pve/lxc/100.conf -> Add: mp0: /rpool/data,mp=/mnt/storage
4. Inside CT 100 Shell:
   apt update && apt install -y samba
   printf "[Storage]\n   path = /mnt/storage\n   writable = yes\n   guest ok = no\n" >> /etc/samba/smb.conf
   smbpasswd -a root (Set your NAS password)
   systemctl restart smbd

===============================================================================
STAGE 6: DEV WORKSTATION (LINUX MINT VM)
===============================================================================
1. Create VM: ID 105, 8 Cores (Type: Host), 16GB RAM (No Ballooning), 100GB Disk.
2. Inside Mint Terminal:
   sudo apt update && sudo apt install xrdp -y
   sudo adduser xrdp ssl-cert
   echo "exec startlinuxmint" > ~/.xsession
3. Fix Wayland: sudo nano /etc/gdm3/custom.conf -> Uncomment WaylandEnable=false.

===============================================================================
STAGE 7: GAME SERVER (PTERODACTYL VM)
===============================================================================
1. Create VM: ID 110, Ubuntu 22.04, 8 Cores, 24GB RAM, 150GB Disk.
2. Inside VM Shell:
   bash <(curl -s https://pterodactyl-installer.se)
   * Choose Option 2 (Panel + Wings).
   * Follow prompts for FQDN (use 192.168.1.110).

===============================================================================
STAGE 8: TAILSCALE REMOTE ACCESS (LXC)
===============================================================================
1. Create CT: ID 115, Ubuntu 22.04, 512MB RAM.
2. Enable TUN on Host: 
   Edit /etc/pve/lxc/115.conf -> Add:
   lxc.cgroup2.devices.allow: c 10:200 rwm
   lxc.mount.entry: /dev/net/tun dev/net/tun none bind,create=file
3. Inside CT 115:
   curl -fsSL https://tailscale.com/install.sh | sh
   tailscale up --advertise-routes=192.168.1.0/24
4. Tailscale Admin Console: Machines -> [CT 115] -> Edit Route Settings -> Approved.

===============================================================================
STAGE 9: CLIENT-SIDE SETUP (YOUR LAPTOP)
===============================================================================
WINDOWS 11:
1. Install Tailscale & Login.
2. Map Drive: File Explorer -> Map Network Drive -> \\192.168.1.51\Storage.
3. Remote Desktop: Use native RDP to 192.168.1.105.

UBUNTU 24.04:
1. Install Tailscale: curl -fsSL https://tailscale.com/install.sh | sh
2. Mount NAS: 
   sudo apt install cifs-utils
   sudo mount -t cifs -o username=root //192.168.1.51/Storage /mnt/your_folder
3. Remote App: Use 'Remmina' (RDP) to 192.168.1.105.
