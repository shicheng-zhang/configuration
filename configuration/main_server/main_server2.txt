#######################################################################
#       THE "WHOLE SHEBANG" SERVER SETUP GUIDE: HP PROLIANT DL360 G7
#       TARGET: Proxmox VE + NAS + Media + Desktop + Game Server
#       HARDWARE: Dual Xeon, 72GB RAM, 3x 980GB SSD/SAS
#######################################################################

---
PHASE 1: HARDWARE & BIOS PREPARATION
---
Goal: Prepare the server to run Virtual Machines and allow Proxmox to manage drives directly.

1.  BOOT TO BIOS
    - Power on the server.
    - Press [F9] repeatedly when you see the HP logo to enter "RBSU" (BIOS).

2.  ENABLE VIRTUALIZATION
    - Navigate to: System Options -> Processor Options.
    - Set "Intel(R) Virtualization Technology" to [Enabled].
    - Set "Intel(R) VT-d" to [Enabled].
    - Press [Esc] to go back.

3.  CONFIGURE STORAGE CONTROLLER (Smart Array P410i)
    *CRITICAL*: ZFS requires direct access to drives. The P410i does not support true "Pass-through."
    *WORKAROUND*: We must create single-disk RAID 0 arrays for each drive.
    
    - Save BIOS settings and Reboot.
    - Press [F8] when you see the "Option ROM" message for the Storage Controller.
    - Select "Create Logical Drive".
    - Select ONLY the first drive. Set RAID Level to "RAID 0". Save.
    - Repeat this process for the second drive.
    - Repeat for the third drive.
    - Result: You should have 3 Logical Drives.

4.  BOOT ORDER
    - Enter BIOS [F9] again.
    - Go to "Boot Controller Order". Ensure the Smart Array is #1.
    - Go to "Standard Boot Order". Ensure USB Drive is #1 (for installation).

---
PHASE 2: PROXMOX VE INSTALLATION (BARE METAL)
---
Goal: Install the Type-1 Hypervisor.

1.  CREATE INSTALL MEDIA
    - On your PC: Download "Proxmox VE ISO" (latest version).
    - Download "Rufus".
    - Plug in a USB stick. Open Rufus.
    - Select the ISO. *IMPORTANT*: When prompted, select "Write in DD Image mode".
    - Click Start.

2.  INSTALLATION
    - Plug USB into HP Server. Boot.
    - Select "Install Proxmox VE".
    - EULA: Click "I agree".
    - TARGET HARD DISK: 
        - Click "Options".
        - Filesystem: Select "zfs (RAID1)". *Note: With 3 drives, select RAIDZ-1 for parity*.
        - Harddisks: Select all 3 drives shown (/dev/sda, /dev/sdb, /dev/sdc).
        - Click OK -> Next.
    - COUNTRY/TIMEZONE: Set to your location.
    - PASSWORD: Set a strong root password. ENTER YOUR EMAIL (required for alerts).
    - NETWORK CONFIGURATION:
        - Management Interface: Select the active ethernet port.
        - Hostname: pve.home (or similar).
        - IP Address: 192.168.1.100 (Example - MUST be outside your router's DHCP range).
        - Gateway: 192.168.1.1 (Your router's IP).
        - DNS Server: 1.1.1.1 or 8.8.8.8
    - FINISH: Remove USB when it reboots.

3.  FIRST LOGIN
    - Go to your PC browser.
    - URL: https://192.168.1.100:8006 (Ignore SSL warning).
    - User: root
    - Password: [The one you set].

4.  POST-INSTALL OPTIMIZATION (ZFS RAM CAP)
    - In Proxmox Web UI, click your node (pve) -> Shell.
    - Type exactly:
      echo "options zfs zfs_arc_max=8589934592" > /etc/modprobe.d/zfs.conf
      update-initramfs -u
    - Reboot the server (Click "Reboot" at top right).

---
PHASE 3: REMOTE ACCESS (TAILSCALE)
---
Goal: Access the server from anywhere without port forwarding.

1.  INSTALL TAILSCALE ON HOST
    - Open Proxmox Shell.
    - Run: curl -fsSL https://tailscale.com/install.sh | sh
    - Run: tailscale up
    - Copy the URL provided and paste it into your browser to authenticate.
    - *Result*: Your server is now accessible via the Tailscale IP (e.g., 100.x.x.x) from any device with Tailscale installed.

---
PHASE 4: THE NAS (OpenMediaVault)
---
Goal: Central file storage accessible by Windows/Mac/Linux.

1.  CREATE VM
    - Click "Create VM".
    - Name: OMV-NAS | ID: 100
    - OS: Upload OMV ISO -> Select it.
    - System: Defaults.
    - Disks:
        - Bus/Device: SCSI
        - Storage: local-zfs
        - Disk size: 32 GiB (OS only).
    - CPU: 2 Cores. Type: Host.
    - Memory: 4096 (4GB).
    - Network: VirtIO (bridge=vmbr0).
    - Finish.

2.  ADD DATA STORAGE
    - Click VM 100 (OMV-NAS) -> Hardware -> Add -> Hard Disk.
    - Bus: SCSI.
    - Storage: local-zfs.
    - Disk size: 1200 GiB (1.2TB). *Adjust based on total pool size*.
    - Click Add.

3.  INSTALL & CONFIG
    - Start VM -> Console. Install OMV (Follow on-screen prompts).
    - Once installed, open browser: http://[OMV-IP-ADDRESS].
    - User: admin | Pass: openmediavault
    - Dashboard -> Storage -> File Systems -> Create -> Select /dev/sdb (1.2TB) -> Format EXT4.
    - Mount the file system. APPLY CHANGES.
    - Storage -> Shared Folders -> Create -> Name: "Data" -> Select File System.
    - Services -> SMB/CIFS -> Settings -> Enable.
    - Services -> SMB/CIFS -> Shares -> Add -> Select "Data" folder.
    - *Verification*: Open Windows Explorer -> \\192.168.1.x -> You should see "Data".

PHASE 5: MEDIA SERVER (Jellyfin)
---
Goal: Stream media using hardware efficiency (LXC).

1.  INSTALL VIA SCRIPT
    - Open Proxmox Shell (Host).
    - Run: bash -c "$(wget -qLO - https://github.com/tteck/proxmox-scripts/raw/main/ct/jellyfin.sh)"
    - Settings:
        - Privileged Container: YES (Important for mounting NAS).
        - Cores: 8 (Since no GPU, CPU needs raw power).
        - RAM: 8192 (8GB).
        - IP: Static (e.g., 192.168.1.110).

2.  MOUNT NAS STORAGE TO JELLYFIN
    - In Proxmox UI: Datacenter -> Storage -> Add -> SMB/CIFS.
        - ID: nas-media
        - Server: [OMV IP]
        - Share: Data
        - Content: Disk Image, ISO, Container.
    - Open Proxmox Shell.
    - Edit container config (assuming ID is 101):
      nano /etc/pve/lxc/101.conf
    - Add line at bottom:
      mp0: /mnt/pve/nas-media,mp=/media
    - Ctrl+O (Save), Ctrl+X (Exit).
    - Restart Jellyfin Container.

3.  SETUP
    - Browser: http://192.168.1.110:8096
    - Add Media Library -> Folders -> Select /media.

---
PHASE 6: DAILY DRIVER (Desktop Environment)
---
Goal: A full Linux workstation you can code on.

1.  CREATE VM
    - Name: Dev-Desktop | ID: 102
    - OS: Linux Mint Cinnamon or Ubuntu Desktop ISO.
    - System: Graphics -> Default.
    - Disk: 100 GiB (local-zfs).
    - CPU: 6 Cores. Type: Host.
    - Memory: 16384 (16GB).
    - Finish.

2.  SETUP
    - Start VM -> Console. Install OS.
    - Once in Desktop, open Terminal.
    - Update: sudo apt update && sudo apt upgrade -y

3.  RUSTDESK SETUP (Remote Access)
    - Download .deb from rustdesk.com inside the VM.
    - Install: sudo apt install ./rustdesk*.deb
    - *Fix Wayland Issue*:
        - sudo nano /etc/gdm3/custom.conf (Ubuntu) OR /etc/lightdm/lightdm.conf (Mint)
        - Uncomment/Add: WaylandEnable=false
        - Reboot VM.
    - Open RustDesk -> Note the ID and Password.

4.  CONNECT TO NAS
    - File Manager -> Other Locations.
    - Connect to Server: smb://[OMV-IP]/Data
    - Right-click the mounted folder -> Add Bookmark.

---
PHASE 7: GAME SERVER (Pterodactyl)
---
Goal: Hosting Minecraft/Valheim via a Web Panel.

1.  CREATE VM
    - Name: Game-Server | ID: 103
    - OS: Ubuntu Server 22.04 or 24.04 (No GUI).
    - Disk: 150 GiB.
    - CPU: 8 Cores.
    - Memory: 24576 (24GB).
    - Finish & Install Ubuntu Server.

2.  INSTALL PTERODACTYL
    - Login to Ubuntu Server terminal.
    - Run: sudo -i
    - Run: bash <(curl -s https://pterodactyl-installer.se)
    - Prompt 1: Select "Install Panel and Wings" (Usually option 2 or similar).
    - Database Name: pterodactyl
    - Username/Pass: Set secure credentials.
    - FQDN: Use the VM's static IP (e.g., 192.168.1.120).
    - Firewall: Choose "Yes" to configure firewall automatically.
    - Let the script run (takes 10-15 mins).

3.  ACCESS
    - Browser: http://192.168.1.120
    - Login with credentials created during script.
    - Create Location: "Home".
    - Create Node: "Home-Node".
    - Allocations: Add IP 192.168.1.120 and Ports (e.g., 25565 for Minecraft).
