


1. First-time setup (do once)
git config --global user.name  ""
git config --global user.email "your-email@example.com"
git config --global color.ui auto
git config --global init.defaultBranch main

2. Create new local repo
cd /path/to/your/project
git init

3. Daily local workflow
git status                          # always start here
git add .                           # stage everything
git add file.cpp video-to-ascii.cpp
git commit -m "Add ASCII video renderer with OpenCV"
git log --oneline --graph -8        # nice compact history

4. Connect to remote (GitHub)
# If starting from local → add remote
git remote add origin https://github.com/username/repo.git

# If cloning existing repo
git clone https://github.com/username/repo.git

# First push (sets upstream tracking)
git push -u origin main

# Normal push after that
git push

5. Sync with remote (very important!)
git pull                            # fetch + merge (most common)
# or: git pull --rebase             # cleaner linear history
git fetch                           # only download, don't merge

6. Fix "non-fast-forward" push error (your recent issue)
git pull origin main                # bring remote changes + merge
# If conflicts → edit files, then:
# git add <fixed-files>
# git commit

# After pull succeeds:
git push origin main

Alternative (clean history, no merge commit):
git pull --rebase origin main
git push origin main

7. Delete / remove existing folder from repo

A. Delete folder everywhere (GitHub + local disk)
git rm -r folder-name
git commit -m "Remove old-videos directory"
git push origin main

B. Remove from GitHub/repo only (keep folder locally – most common!)
git rm -r --cached folder-name
git commit -m "Stop tracking node_modules / videos / logs"

# Prevent adding it again
echo "folder-name/" >> .gitignore
git add .gitignore
git commit -m "Ignore folder-name going forward"
git push origin main

Examples:
git rm -r --cached videos
git rm -r --cached build
git rm -r --cached .vscode

8. Branches – quick reference
git branch                          # list
git switch -c feature-better-ascii  # create + switch
git switch main                     # go back
git pull origin main                # update main first
git merge feature-better-ascii      # merge into current branch
git push origin feature-better-ascii

9. Undo / danger zone commands
git restore .                       # discard all uncommitted changes
git restore --staged .              # unstage everything
git reset --hard HEAD               # nuclear – back to last commit

# Amend last commit
git commit --amend -m "Better message"
git commit --amend --no-edit        # just fix files you forgot

10. See what changed
git diff                            # unstaged changes
git diff --staged                   # staged vs last commit
git show HEAD~1                     # previous commit + diff
git log -p -3                       # last 3 commits with full diff

Quick daily flow reminder
git pull
# work...
git status
git add .
git commit -m "fix frame timing calculation"
git push

When in doubt → git status + git log --oneline --graph --all -12
